# No.003「ノアの方舟」動作確認

確認日：2026-10-21。既存 `sawanoto/BibleSketch` のNo.2完成ブランチを土台に、No.3の独立フォルダを追加。No.2のPRが未マージのため、No.3も積み上げPRとして作成します。

## 確認結果

ローカルHTTP配信とChromium / Playwrightで、実際のマウス・タッチ入力を使用しました。

| 確認 | 結果 |
| --- | --- |
| PC 1440×1000、マウス | 森林・海・草原の3地点をそれぞれ操作し、全て再生後まで自動進行 |
| モバイル相当390×844、タッチ・DPR 3 | 海へのドラッグと再生まで成功。Canvas密度は最大2 |
| 落下予想 | ドラッグ中に縦線・照準・環境名を表示 |
| 落下位置 | 連続した指定X座標と一致（許容差0.5%未満） |
| 一度だけの落下 | 確定後の操作・再dropを拒否。落下数は1のまま |
| 誤操作・キャンセル | 単なるクリック、画面外での解放、touchCancelでは落下しない |
| 衝突演出 | 閃光、衝撃波、短い揺れ、粉塵、植物・生物の減少、暗転を表示。海は大波も表示 |
| 暗期の静寂 | 全音源数0、解析ノードの波形も無音 |
| 生存結果 | 森林27、海19、草原26。3シナリオで構成が異なる |
| 非鳥類型恐竜 | 全地点で生存0、子孫0 |
| 生存の決め方 | 同地点で同結果。距離・避難場所で個体を順位付け。同じ森林内でも位置により選ばれる個体が変わる |
| 再生後 | 森林落下68、海50、草原65個体。全て生存者と同じ分類の子孫で、親IDが実在することを確認 |
| 個体数の上限 | 全シナリオで128以下 |
| 方舟の象徴 | 再生後の最初の約3.2秒だけ輪郭を表示。その後は自由に眺められる |
| PNG | 全6場面を3840×2400へ出力。タッチ環境で全6場面の2560×1600と3840出力も成功 |
| 書き出しの独立性 | 落下点・生存個体・段階・落下数に変更なし。通常Canvas寸法・密度に復帰 |
| 消音・再開 | 消音時は音源数0、表示・aria-pressedも切り替え |
| リセット | 落下前へ戻り、場面記録は1枚へ初期化。進行中の落下をリセットしても後で衝突しない |
| キーボード | 左右矢印・Enter/Spaceから落下し再生後まで成功 |
| 動きを減らす・AudioContext非対応 | 弱い光・揺れ抑制の設定で進行成功。音声APIが失敗しても停止しない |
| レイアウト | トップ・作品・解説を320 / 390 / 1440pxで確認し、横方向のはみ出しなし |
| 回転・リサイズ | 844×390、950×700への変更でも横方向のはみ出しなし |
| JavaScript実行エラー・必須ファイルHTTPエラー | なし |
| No.1回帰 | PC・タッチ、1〜7日、保存・復帰、全PNG、消音・回転が成功 |
| No.2回帰 | PC・タッチ、両結末・向き直る分岐・無音・全PNG・キーボード・音声/保存領域非対応が成功 |
| 既存コード | `001-creation/`・`002-cain-and-abel/`・`shared/`・`vendor/` はNo.2完成ブランチと差分なし |

生存数は作品で決めた仮想個体数で、実際の衝突・大量絶滅を予測する数値ではありません。音はAPI・波形で開始と無音を検証し、実際のスピーカー出力を聴いて評価したわけではありません。

## 再現

PlaywrightとChromiumのある開発環境で、リポジトリルートを配信します。

```sh
python3 -m http.server 8000
# 別ターミナル
npm ci
CHROMIUM_PATH=/usr/bin/chromium npm run test:noah
CHROMIUM_PATH=/usr/bin/chromium npm test
CHROMIUM_PATH=/usr/bin/chromium npm run test:cain-abel
```

No.3のテストはdocsのNo.3サンプルを再生成します。No.1・No.2テストもそれぞれのサンプルを再生成するため、不要なランダム差分をコミットしないでください。モデル単体は `node tests/noah-model.cjs`。No.3のHTTP配信先は `TEST_BASE_URL` で変更できます。

## 公開方法

1. 先にNo.2のPRをmainへマージ。
2. No.3のPRのbaseをmainに変更（GitHubが自動変更していれば確認）。
3. No.3のPRをマージ。
4. 既存のGitHub Pages（main / root）のデプロイ成功後、`https://sawanoto.github.io/BibleSketch/003-noahs-ark/` を確認。

PRの作成・ブランチのpushだけでは本番には反映されません。追加のリポジトリ・サーバー・APIキーは不要です。

## 未確認・制約

- 実機iOS Safari / Android Chromeの聴感・音量、長押し保存・共有先メニュー、低メモリ機での性能は未確認。
- 30fpsを目標に描画し、密度2・個体128・有限の音源へ制限していますが、実機のフレームレートを保証するものではありません。
- 高解像度PNGの生成では一時的な処理負荷が発生します。低メモリ機では2560×1600を選択してください。
- 今回のプレイの記録はメモリ内のみ。リセット・ページ再読み込みで消え、端末間同期はありません。
- 生存・植物の再生・時間経過は創作上のモデル。地球史の厳密な再現、隕石衝突とノアの洪水を同一視する学説の提示ではありません。
- Kindle最終組版・色校正・KDP入稿は別途必要です。
