# No.002「カインとアベル」動作確認

確認日：2026-10-21。既存の `sawanoto/BibleSketch` の日英併記版 `main` から作業ブランチで追加。新しいリポジトリは作成していません。

## 結果

ローカルHTTP配信とChromium / Playwrightで確認しました。

| 確認内容 | 結果 |
| --- | --- |
| PC 1440×1000、マウス | 両方の結末を通して成功 |
| スマートフォン相当390×844、タッチ・DPR 3（描画密度は2に制限） | 両方の結末を通して成功 |
| 捧げる → 弟だけに光 → 怒り → 分岐 | 成功。演出中は分岐操作を無効化 |
| 光の範囲 | 兄の籠付近の画素は前後一致、弟側だけ変化 |
| 弟への1回目・2回目・3回目 | 睨み・怯え・暗転へ順に進む |
| 意図しない連続操作 | 0.35秒未満の連打で段階が飛ばない |
| 弟の消失後 | 操作対象・羊・弟の名前も消え、兄と籠だけが残る |
| 消失後の音 | 音源数0。解析ノードの波形も無音。消音を解除しても再生なし |
| 途中で弟から籠へ向き直る | 弟への2回の操作後、籠を4回整えて別の結末へ進める |
| もう一つの結末 | 弟は残り、兄の怒りは収束。兄の籠に承認の光は追加されない |
| リセット | 段階・操作回数が初期化。演出中のリセットで遅れて遷移・音が再開しない |
| 場面記録 | やり直し後と同じタブの再読み込み後も、両結末を含む6場面を選択可能 |
| PNG | 全6場面を3840×2400、タッチ環境では全6場面を2560×1600で成功。タッチ環境の3840出力も成功 |
| 書き出し後 | 分岐・操作回数は変化せず、Canvasの通常サイズ・描画密度へ復帰 |
| レイアウト | トップ・作品・解説を320 / 390 / 1440pxで確認、横方向のはみ出しなし |
| 回転・サイズ変更 | 844×390、950×700への変更後も横方向のはみ出しなし |
| キーボード | Tab・Enter / Spaceによる捧げる・籠を整える操作から結末へ到達 |
| 動きを減らす設定 | 有効時も進行成功 |
| AudioContext・保存領域が利用不可 | エラーで停止せず結末へ到達。英語を含む案内を確認 |
| No.1回帰 | 既存 `npm test` のPC・タッチ、1〜7日、保存と復帰、全PNG、音開始・消音・回転が成功 |
| JavaScript実行エラー・必要ファイルのHTTPエラー | なし |
| 共通描画・既存作品 | `001-creation/`・`shared/`・`vendor/` に差分なし |

## 再現

PlaywrightとChromiumのある開発環境で、リポジトリルートを配信します。

```sh
python3 -m http.server 8000
# 別ターミナル
npm ci
CHROMIUM_PATH=/usr/bin/chromium npm run test:cain-abel
CHROMIUM_PATH=/usr/bin/chromium npm test
```

No.002テストの配信先は `TEST_BASE_URL` で変更可能。テストはdocsの画面・場面サンプルを再生成します。No.1テストも既存の `docs/desktop.png` / `docs/mobile.png` を再生成するため、不要なランダム差分をコミットしないでください。

## 公開と制約

- PRの確認・mainへのマージ後、既存のGitHub Pagesが `https://sawanoto.github.io/BibleSketch/002-cain-and-abel/` に配信します。PR作成だけでは本番に反映されません。
- 実機iOS Safari / Android Chromeでの聴感・音量、長押し保存、OSの共有先UI、低メモリ機の性能は未確認です。音はAPIの開始と停止・無音を検証し、スピーカー出力を聴いて評価したわけではありません。
- 30fpsを目標に描画。タッチ領域は最低44px、アートの縦横比は固定、描画密度は最大2。実機でのフレームレートの保証ではありません。
- sessionStorageの記録は同じタブ内のものです。タブ終了・保存領域消去で失われ、端末間同期はありません。保存領域がない場合はページを開いている間だけ記録を保持します。
- PNG生成時は短時間の処理負荷が発生します。低メモリ端末では2560×1600を推奨。Kindleの最終組版・色校正・入稿は別途必要です。
