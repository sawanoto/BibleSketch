## 再現方法

別端末では `npm ci` とChromiumの用意が必要（通常閲覧には不要）。

```sh
python3 -m http.server 8000
# 別ターミナルで
npm ci
CHROMIUM_PATH=/usr/bin/chromium npm test
```

`CHROMIUM_PATH` は使用環境の実際のChromium実行ファイルに変更する。
