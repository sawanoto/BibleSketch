# No.004「バベルの塔」動作確認

確認日：2026-10-21。既存の `sawanoto/BibleSketch`、No.3完成ブランチを土台にNo.4を追加。既存作品や共通マーパンを変更せず、No.4単独の差分として作成します。

## 結果

ローカルHTTP配信、Chromium / Playwrightで実際のマウス・タッチ・キーボード入力を使用しました。

| 確認 | 結果 |
| --- | --- |
| PC 1440×1000、マウス | 8体で操作から完成まで成功 |
| モバイル相当390×844、タッチ、DPR3 | 6体で操作から完成まで成功。描画密度は最大2 |
| 初期状態 | 上下左右が全て混在し、塔は土台のみ |
| 方向循環 | 左→下→右→上→左。一回の入力につき変更数が1増える |
| 上向きの再操作 | 全員一致前なら左向きへ戻せる |
| 全員一致前の制止 | 7/8・5/6で待っても進行0・planningを維持。モデル単体でも30秒待機して成長なし |
| 一致の瞬間 | 最後の上向き操作でbuildingへ即遷移。建設開始数1 |

| リセット | planning・進行0・上下左右混在へ戻り、記録は初期場面だけへ |

## 再現

PlaywrightとChromiumのある開発環境で実行します。通常の作品閲覧にはnpmの準備は不要です。

```sh
python3 -m http.server 8000
# 別ターミナル
npm ci
CHROMIUM_PATH=/usr/bin/chromium npm run test:babel
CHROMIUM_PATH=/usr/bin/chromium npm test
CHROMIUM_PATH=/usr/bin/chromium npm run test:cain-abel
CHROMIUM_PATH=/usr/bin/chromium npm run test:noah
```

モデル単体は `node tests/babel-model.cjs`。No.4のテスト配信先は `TEST_BASE_URL` で変更できます。各作品のテストはその作品のdocs画像を再生成するので、既存作品の不要なランダム画像差分をコミットしないでください。

## 制約・未確認

- 実機iOS Safari / Android Chromeでの聴感・音量、長押し保存・OS共有先UI、低メモリ端末での性能は未確認。
- 30fpsを目標に描画しますが、実機のフレームレート保証ではありません。
- 高解像度PNGは一時的に処理負荷が増えます。低メモリ機では2560×1600を選んでください。
- 記録は今回のプレイのメモリ内だけで、リセット・再読み込みで初期化し、端末間同期はありません。
- Kindle最終組版・色校正・KDP入稿は別途必要です。
